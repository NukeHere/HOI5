# Сохранения игры

Кнопка «Загрузить игру» доступна в главном меню и меню Escape. В меню Escape также есть «Сохранить игру». «Сохранить игру» открывает список в режиме сохранения. Можно выбрать существующий файл и подтвердить перезапись либо нажать «Новое сохранение», ввести имя и сохранить. «Загрузить игру» открывает отдельный режим, в котором запись не выполняется. В обоих режимах доступно переименование. Файлы находятся в %LOCALAPPDATA%/HOI5/saves рядом с пользовательскими настройками; без LOCALAPPDATA используется saves рядом с исполняемым файлом.

В списке показаны страна, прошедшие игровые часы, сид и версия игры. При несовпадении версии игры или формата появляется предупреждение и кнопка «Загрузить всё равно». Отличающаяся версия игры сама по себе не запрещает загрузку. Неизвестный формат можно попытаться загрузить, но текущий читатель завершит попытку понятной ошибкой: миграция неизвестных форматов не имитируется. Повреждённый файл не заменяет текущую партию.

Снимок содержит карту целиком, владение, население, залежи, здания, дивизии и их приказы/снабжение/шаблоны, армии, бои, авиацию/ПВО/снаряды, производство, запасы, финансы, торговлю, политику/дипломатию/гражданские войны, новости и состояние планировщиков ИИ. Сохраняются генераторы случайных чисел, симуляционные часы и следующий торговый цикл. Индекс производных экономических данных пересоздаётся по сохранённому миру. Панели интерфейса и выделение очищаются штатным обработчиком нового мира.

Файл: текстовый заголовок HOI5_SAVE, номер формата, версия игры, сид, часы, страна, длина и FNV-1a контрольная сумма; далее двоичный снимок (little endian, IEEE754). Запись идёт во временный файл с последующим переименованием. Новый файл не заменяет существующий без подтверждения. Подтверждённая перезапись на Windows использует атомарную замену через MoveFileExW; при ошибке записи исходный сейв сохраняется. Загрузка сначала создаёт отдельный World и меняет активный мир только после успешного чтения.

## Развитие формата

Текущий формат: 2. Сохранения раннего формата 1 читаются с восстановлением отсутствующих производных сводок. При отличии формата или версии меню показывает предупреждение; исходный файл при загрузке не меняется. Порядок полей World указан явно в World::saveFields. Для обычных структур архив обходит все агрегатные поля; закрытые классы предоставляют saveFields. Любое изменение структуры или порядка сериализуемых полей требует увеличения formatVersion и, при необходимости, отдельного читателя/миграции предыдущего формата. Указатели на боеприпасы восстанавливаются по ключу; строковые представления получают хранилище с временем жизни загруженного мира. Шаблоны дивизий восстанавливаются с сохранением ссылок на стандартные и пользовательские проекты.

## Проверки

HOI5.exe --check-save-game <тестовая папка> — полное сравнение снимка до/после загрузки, пользовательский шаблон, 24 часа дальнейшего развития, загрузка с другой версией игры, отказ при повреждении/обрезании/неизвестном формате без изменения часов текущей партии. CTest: save_game_roundtrip.

HOI5.exe --smoke-save-menu <PNG> — снимок меню по тестовым файлам из save-test рядом с exe, с выбранной отличающейся версией. Не создаёт пользовательских сохранений.

HOI5.exe --smoke-save-flow — проверяет реальные обработчики кнопок: сохранить из Escape, загрузить созданный файл, открыть загрузку из Escape, вернуться в главное меню и загрузить оттуда. Использует уникальную тестовую подпапку save-flow рядом с exe. Также проверяет именованный сейв, отмену перезаписи и переименование.

HOI5.exe --check-save-file <файл> — читает существующий сейв без изменения файла и сообщает размер мира, число стран, дивизий и игровое время.

Итоговая проверка: 59/59 CTest, сценарий интерфейса с новым именем/отменой перезаписи/переименованием/загрузкой из двух меню; отдельно подтверждены перезапись и русские имена. Все 24 существовавших пользовательских сейва успешно прочитаны без изменения файлов. Старый нулевой сид восстанавливается из состояния новостей, если он присутствует в снимке.
