# Зависание воздушного боя и размещение CAS

22 ноября 2026.

## Причина

При выборе истребителей для перехвата всех кандидатов оценивали по одному текущему национальному запасу топлива. Затем каждому кандидату списывали топливо без повторной проверки. Два крыла одной страны могли потратить один и тот же остаток. При отрицательном запасе `fighterEngagement` возвращал отрицательное число самолётов; проверка `if (!engaged)` его не отсекала. Это отрицательное число попадало в `std::binomial_distribution`, нарушая её предусловие о неотрицательном числе испытаний. В используемой реализации MinGW цикл ожидания может не завершиться для отрицательного числа испытаний.

## Исправление

Оценка перехвата всегда неотрицательна. Перед каждым фактическим вылетом повторно проверяются общий запас топлива и боекомплект — и против самолётов, и против ракет. Несостоявшийся вылет не списывает ресурсы. Обёртка случайного числа попаданий отсекает нулевые/отрицательные испытания и недопустимые вероятности. Для обычных допустимых параметров сохранено прежнее биномиальное распределение, а не введён иной баланс боя.

Это исправляет конкретный обнаруженный механизм зависания; по скриншотам нельзя доказать, что все три пользовательских случая вызваны только им.

## Диагностика и проверки

До исправления военный сценарий `--check-economic-development 146591 730 war 80 11 3` не завершился за 45 секунд, последний CSV — 210-е сутки. Запущенная с трассировкой версия повторно остановилась на `server_air_attack_salvos`. Проверки добавлены в `--check-air-patrol`: два крыла и топливо только для одного перехвата самолёта/ракеты, запрет вылета при отрицательном остатке. `bounded_air_combat_sampling` проверяет отрицательное число испытаний, границы вероятностей, повторяемость по сиду и среднюю частоту попаданий.

Опциональная переменная окружения `HOI5_TRACE_STEPS` задаёт путь журнала этапов. Без неё файлового ввода-вывода нет. Журнал не является сохранением. Оригинальные пользовательские сейвы не изменялись. Формат сохранений этой правкой не меняется.

Дополнительно включена ранее запрошенная правка районов CAS и регрессия назначения фронта, описанные в `cas-front-deployment.md`.

## Результат

Release build и 61/61 CTest прошли. Военный мир 80×80, 11 стран, Impossible, сид 146591 после исправления достиг 730 суток с трассировкой; ранее тот же сценарий останавливался в воздушном бою после 210 суток. Новые сценарии двух крыльев с общим дефицитным топливом прошли для перехвата самолёта и ракеты. Данные проверки находятся в `build/hang-audit/`; прогон не является доказательством отсутствия всех возможных зависаний на любых сейвах.
