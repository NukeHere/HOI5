# Реестр переноса Python → C++

В `port_progress.tsv` каждая строка соответствует одному объявлению класса,
функции или метода. Вложенные функции тоже учитываются. Поля `cpp` и
`evidence` фиксируют реализацию и основание для статуса.

- `ported` — подтверждено соответствие. Одна строка даёт одну единицу прогресса.
- `partial` — найдено соответствие с известными расхождениями.
- `missing` — проверено, что реализации нет.
- `unreviewed` — соответствие ещё не проверено.
- `excluded_bot` и `excluded_tool` — логика ботов, тесты и вспомогательные сценарии. Они перечислены в реестре и вынесены из знаменателя игровой версии.

После переноса меняйте статус и основание только в затронутых строках.
`python H5_CPP/port_progress.py` проверяет актуальность реестра и выводит счётчик.
Если изменились объявления Python, запустите `python H5_CPP/port_progress.py --sync`.
Синхронизация обновит строки и сохранит существующие статусы по имени объявления.

Подтверждённый процент — число строк `ported`, делённое на число объявлений в
игровом объёме. Пока есть строки `unreviewed`, это нижняя граница по аудиту.
